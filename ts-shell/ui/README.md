# GridHammer UI

Read-only visualization for GridHammer simulation artifacts.

## Purpose

*   Visualize `evse_states.jsonl` as timelines.
*   Visualize `ocpp_trace.jsonl` (Planned).
*   Diff runs (Planned).

**Note**: This UI is strictly read-only. It does not control the simulation.

## Usage

1.  Run the development server:
    ```bash
    npm run dev
    ```
2.  Open the browser.
3.  Drag and drop an `evse_states.jsonl` file from a run artifact directory.

## Artifacts

The UI expects artifacts generated by `gridhammer-core`.
